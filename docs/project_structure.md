# Project Structure

This document explains the folder structure of the AWS Financial Operations Data Pipeline project.

## Folder Overview

```text
aws-financial-operations-data-pipeline/
│
├── data/
│   ├── raw/
│   ├── processed/
│   └── curated/
│
├── scripts/
│
├── dashboard/
│
├── docs/
│
├── sql/
│
├── README.md
├── requirements.txt
└── .gitignore
```

## Data Layers

### `data/raw/`

Stores raw CSV files generated by the ingestion layer.

These files may contain intentional data quality issues such as:

* missing values
* duplicate records
* invalid statuses
* invalid dates
* invalid references

### `data/processed/`

Stores cleaned CSV files after validation and cleaning.

This layer contains data that is ready for transformation.

### `data/curated/`

Stores analytics-ready Parquet files and business reports.

This layer is designed for reporting, dashboarding, and future Athena queries.

## Scripts

### `generate_*.py`

Creates realistic synthetic raw data.

### `validate_*.py`

Checks data quality issues without modifying the raw files.

### `clean_*.py`

Creates cleaned datasets in the processed layer.

### `convert_processed_to_parquet.py`

Converts cleaned CSV files into Parquet format.

### `generate_business_metrics.py`

Creates business KPI outputs from curated Parquet data.

## Dashboard

### `dashboard/app.py`

Streamlit dashboard for showing business KPIs and simple analytics charts.

## Future AWS Mapping

The local layers map to AWS as follows:

```text
data/raw/       → s3://bucket/raw/
data/processed/ → s3://bucket/processed/
data/curated/   → s3://bucket/curated/
```

Future AWS services:

* Amazon S3 for data lake storage
* AWS Glue Data Catalog for table metadata
* Amazon Athena for SQL analytics
* IAM for access control
