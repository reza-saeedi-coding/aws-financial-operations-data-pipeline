# Project Plan

## Project name

AWS Financial Operations Data Pipeline

## Subtitle

Cloud Data Pipeline for Business Operations Analytics

## First local stages

1. Create project structure.
2. Generate mock CSV files.
3. Validate schemas and duplicates.
4. Create processed data outputs.
5. Convert curated data to Parquet.

## Cloud stages

1. Upload raw and curated data to AWS S3.
2. Catalog data with AWS Glue.
3. Query data with Amazon Athena.
4. Build a simple dashboard/report.
